# RC Translate Studio releases

This repository distributes Windows installer releases for RC Translate Studio. The source code is maintained separately in the private [source repository](https://github.com/HeesungYang1/rc-translate-studio).

Download the versioned Windows installer from [Releases](https://github.com/HeesungYang1/rc-translate-studio-releases/releases). Each release includes the installer and its SHA-256 checksum. Verify the checksum before installing.

Installers are currently unsigned. Windows may show its standard publisher warning. The application supports 64-bit Windows 10 and 11.
